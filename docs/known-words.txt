# Known-safe capitalised words — the PERMITTED set.
#
# scripts/unknown_names.py reports capitalised words that appear nowhere else
# in the project's vocabulary, as candidates for being somebody's name. Words
# listed here are silenced.
#
# THIS FILE IS SAFE TO COMMIT, and that is the whole point of its existence.
# It is the opposite of docs/private/forbidden-strings.txt: that one lists
# exactly what must never be published, so publishing it would be the leak.
# This one lists what is fine in public, so publishing it costs nothing.
#
# Adding a line is a deliberate "yes, this word is fine for a stranger to
# read". If you are not sure, leave it out — an extra candidate in a report is
# cheap; a name in the history is not.
#
# One word per line, case-insensitive. Blank lines and # comments ignored.
